# 🌤️ Live Weather Web

A simple and responsive **Live Weather Web Application** that provides real-time weather information for different locations. The project is built using **HTML, CSS, and JavaScript** and fetches live weather data through a weather API.

## ✨ Features

* 🔍 Search weather by city name
* 🌡️ Displays current temperature
* ☁️ Displays current weather condition
* 💧 Shows humidity
* 🌬️ Displays wind information
* 🌍 Fetches real-time weather data from an API
* 📱 Responsive design
* ⚡ Dynamic weather information using JavaScript
* 🎨 Clean and simple user interface

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Weather API**

## ⚙️ How It Works

1. Enter the name of a city in the search field.
2. JavaScript sends a request to the weather API.
3. The API returns the latest weather information.
4. The application processes the response.
5. The weather details are displayed dynamically on the webpage.

## 🔑 API Integration

This project uses a weather API to retrieve real-time weather data.

> ⚠️ If your API requires a key, keep the key private and avoid committing it to a public repository.

## 💻 How to Run Locally

### Clone the repository

```bash
git clone https://github.com/Diptiranjan-Das-4/Live_Weather_Web.git
```

### Open the project

```bash
cd Live_Weather_Web
```

Then open `index.html` in your browser.

For development, you can use the **Live Server** extension in VS Code.
